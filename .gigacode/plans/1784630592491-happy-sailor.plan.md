# План переделки структуры проектов в v2-service к стандартной IDE-архитектуре

## Текущая структура

### Frontend (React)
- **ProjectPage.tsx** - основная страница проекта
  - Есть кнопки "+ файл" и "+ подпроект" в интерфейсе
  - Отображает плоский список файлов и дерево подпроектов
  - Использует `FileTree` для отображения файлов с вложенностью

### Backend (FastAPI)
- **Project** (project.py) - узел дерева с `parent_id` для подпроектов
- **File** (file.py) - плоские файлы внутри проекта
- API эндпоинты:
  - `/projects` - CRUD проектов (с поддержкой `parent_id`)
  - `/projects/{id}/files` - CRUD файлов внутри проекта

### Существующие компоненты
- **ContextMenu.tsx** - уже есть контекстное меню
- **CreateFileDialog.tsx** - диалог создания файла
- **TreeView.tsx** - дерево для подпроектов
- **FileTree.tsx** - дерево файлов

## Требуемая структура

### Новая архитектура
```
Проект (папка)
├── файлы (.ontol/.tdl)
├── папки (поддиректории)
│   ├── файлы
│   └── подпапки
└── подпроекты (отдельные проекты)
```

## Подробный план реализации

### Фаза 1: Backend - поддержка вложенных папок

#### 1.1 Модель Directory
**Файл:** `backend/app/models/directory.py`
```python
class Directory(Base):
    id: UUID
    project_id: UUID
    parent_directory_id: UUID | None
    name: str
    created_at: datetime
    files: List[File]
    children: List[Directory]
```

#### 1.2 Миграция Alembic
**Файл:** `backend/alembic/versions/xxx_add_directories.py`
- Создать таблицу `directory`
- Обновить таблицу `file` для поддержки `directory_id`
- Миграция существующих плоских файлов в новую структуру

#### 1.3 API для папок
**Файл:** `backend/app/api/directories.py`
- CRUD для папок
- Проверка уникальности имени внутри папки
- Проверка пустоты при удалении

**Файл:** `backend/app/schemas/directory.py`
- Схемы для папок (Create, Read, List)

#### 1.4 Обновление существующего API
**Файл:** `backend/app/api/files.py`
- Поддержка создания файлов с путем (например: `path=utils/helpers`)
- Обновление имен файлов с учетом путей

### Фаза 3: Навигация и UX

#### 3.1 Структура деревьев
```
FileTree:
- Папки (📂) - можно разворачивать, создавать файлы/подпапки
- Файлы (📄) - можно открывать, переименовывать, удалять

ProjectTree:
- Подпроекты (📁) - можно создавать подпроекты, переименовывать, удалять
```

#### 3.2 Правая кнопка мыши
**Для файлов:**
- Переименовать
- Удалить

**Для папок:**
- Создать файл
- Создать папку
- Переименовать
- Удалить (если пустая)

**Для проектов/подпроектов:**
- Создать подпроект
- Переименовать
- Удалить

2. **Backend API** - добавить эндпоинты для папок
3. **Frontend API types** - обновить типы для поддержки папок
4. **Frontend FileTree** - добавить контекстное меню
5. **Frontend ProjectTree** - новое дерево проектов
6. **Frontend ProjectPage** - убрать кнопки, использовать новые компоненты
7. **Тестирование** - проверить создание/удаление/переименование

## Проверка

1. Создать проект
2. Правый клик на проект → создать подпроект
3. Правый клик на файл → создать файл, переименовать, удалить
4. Правый клик на папку → создать файл/папку, переименовать, удалить
5. Навигация: двойной клик/клик на файл для открытия
6. Удаление папки с проверкой пустоты
